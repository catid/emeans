# Empirical Scale-Transition & Multi-Gear Power-Law Summary (`scale-law-miner`)

- **Total Validated Runs**: `1,327` (`0` `NaN`/`Inf`, `0` FP8 `0x7f` NaNs, `100%` validation-only splits — zero test/query access).
- **Hardware**: `6x` identical `NVIDIA RTX PRO 6000 Blackwell Max-Q` GPUs (`ripper:0..3`, `loki:0,1`), single-GPU paired per cell.

## 1. Fitted Gear-Switching Rules for `ApexEMeans`

1. **Gear 1 -> Gear 2 (`BF16 + 5-Step CUDAGraph` -> `CroissAttn-FP8 + 5-Step CUDAGraph`)**:
   - Rule: `use_croiss_fp8 = ((n * k * nepochs * ((d / 128.0) ** 0.820)) >= 1.852e+08) and ((d <= 256) or contiguous_tma_prepermuted)` (`R^2 = 0.6992`).
   - Max validation `|Delta MSE|` across all cells (incl. `[0..3800]` sensor skew & `+25` shift): **`1.0272%`** (vs `-0.0947%` for global pow2 FP8 on `multiscale_sensor`).
2. **Gear 2 -> Gear 3 (`Exact CroissAttn-FP8` -> `IVF-Explore (T-1) + 1 Exact FP8 Close` + Huge-K Fast Seeding)**:
   - Rule: `use_ivf_explore_exact_close = (k >= 16384) and (d >= 64) and (n >= 30 * k) and (nepochs >= 2.0)` (`K* = 16,384`, `(N*K)* = 1.64e+10`).
   - Recommended IVF params: `nlist = clamp(round_power_of_two(1.0 * sqrt(K)), 128, 256)  # 1*sqrt(K) hits 1.13x-2.25x vs FP8, 1.55x-3.23x vs BF16`, `nprobe = 8 (or 16 when N >= 4_000_000)`.
   - Mean MSE improvement of **1 Exact Closing Pass** over pure IVF: **`+1.9324%`**.
3. **Gear 3 Scale-Adaptive Algorithmic Knobs**:
   - **Simplex Empirical-Bayes Prior**: `tau*(N/K, D) = clip(6.410 * (N/K)^(-0.199) * D^(-0.075), 0.08, 2.50)`.
